PUT YOUR LOGO HERE
1. Copy your logo file into this folder, for example logo.png
   (PNG with transparent background or SVG is best, about 400 px wide)
2. Optional: a light/white version for dark mode, for example logo-dark.png
3. Open src/lib/brand.ts and set:  logo: "/brand/logo.png"
4. Restart npm run dev and hard refresh (Ctrl+Shift+R).
